# 0023. 서버는 계층 우선 헥사고날 구조로 만들고 도메인끼리 참조하지 않는다

- 상태: 채택
- 날짜: 2026-09-24

## 맥락

다른 서비스가 헥사고날 구조를 씁니다. Auth는 계정, 세션, 권한처럼 서로 얽힌 도메인이 많아 경계가 흐려지기 쉽습니다.

## 결정

- 최상위를 계층으로 나누고, 그 안을 도메인별로 나눕니다.
- 도메인끼리는 호출하거나 필드로 갖지 않고 ID로만 참조합니다. 여러 도메인을 함께 다루는 일은 UseCase가 조합합니다.
- 규칙은 Konsist로 검사합니다([ADR-0025](0025-konsist-architecture-tests.md)).

## 검토한 대안

- 평면 구조(기능별 패키지만): 다른 서비스와 구조가 달라지고 기술 코드와 규칙이 섞입니다.
- 기능 우선 헥사고날: 도메인 간 공유 포트가 많아 중복이 생깁니다.

## 결과

- 규칙이 다른 도메인 정보를 필요로 하면 값으로 받는 설계가 필요합니다.
- 관련 문서: [architecture.md §5](../architecture.md#5-auth-server-구조)
