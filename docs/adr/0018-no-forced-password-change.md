# 0018. 비밀번호 강제 변경 기능을 두지 않는다

- 상태: 채택
- 날짜: 2026-09-24

## 맥락

관리자가 임시 비밀번호를 발급하고 다음 로그인 때 변경을 강제하는 방식은 로그인 흐름을 복잡하게 만들고, 임시 비밀번호가 전달 과정에서 노출됩니다.

## 결정

- 강제 변경 상태(`must_change_password`)와 전용 응답을 두지 않습니다.
- 관리자는 재설정 메일을 보냅니다.

## 검토한 대안

- 임시 비밀번호 + 강제 변경: 위 문제 때문에 제외했습니다.

## 결과

- 비밀번호 만료 정책이 필요해지면 다시 검토합니다.
- 관련 규칙: [PWD-05](../domain.md#4-비밀번호-규칙-pwd)
