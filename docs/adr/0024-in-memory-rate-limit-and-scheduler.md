# 0024. 요청 제한은 인메모리 Bucket4j, 배치는 @Scheduled로 한다

- 상태: 채택
- 날짜: 2026-09-24

## 맥락

초기에는 Auth를 인스턴스 한 대로 운영합니다. 분산 저장소를 두면 운영할 것이 늘어납니다.

## 결정

- 요청 제한은 Bucket4j 인메모리 버킷으로 합니다.
- 정리 배치와 일일 요약은 Spring `@Scheduled`로 실행합니다.
- owner 부트스트랩처럼 한 번만 실행돼야 하는 작업은 DB 잠금(advisory lock 등)으로 보호합니다.

## 검토한 대안

- Redis 요청 제한, ShedLock: 지금 규모에는 과합니다.

## 결과

- 인스턴스를 늘리면 요청 제한 한도가 대수만큼 늘고 스케줄러가 중복 실행됩니다. 그 전에 Redis와 ShedLock을 도입합니다.
