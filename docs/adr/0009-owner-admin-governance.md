# 0009. Auth 관리 권한은 owner 한 명과 admin 여러 명으로 나눈다

- 상태: 채택
- 날짜: 2026-09-24

## 맥락

"모든 권한을 가진 관리자" 하나만 두면 한 사람이 다른 관리자를 정지하거나 자기에게 권한을 줄 수 있습니다.

## 결정

- `auth:owner`는 정확히 한 명이며 양도만 가능합니다. admin 임명·해임, audience 추가, 감사 로그 조회를 합니다.
- `auth:admin`은 계정 관리와 일반 role 부여를 함께 합니다.
- admin은 owner·admin 계정에 대해 어떤 변경도 할 수 없고, 자기 자신에게 role을 줄 수 없습니다.
- admin이 새 계정을 만들어 권한을 주는 우회를 감시하기 위해 감사 로그와 owner 알림을 둡니다.

## 검토한 대안

- 계정 관리자와 role 관리자 분리: 두 명 이상의 관리 체계가 필요하고 지금 규모에는 과합니다.
- 권한 단위 인가(`ACCOUNT_INVITE` 등): 역할 분리가 필요해질 때 도입합니다.

## 결과

- owner 계정은 평소에 쓰지 않습니다.
