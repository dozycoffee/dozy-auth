# 0004. access token 즉시 차단은 지금 지원하지 않는다

- 상태: 채택
- 날짜: 2026-09-24

## 맥락

서비스가 토큰을 로컬에서 검증하므로, 계정을 정지해도 이미 발급된 access token을 막으려면 별도 장치가 필요합니다.

## 결정

- access token 수명을 짧게(`policy.access-token-ttl`) 두고, 정지·비밀번호 재설정 시 refresh 세션만 폐기합니다.
- 즉시 차단이 필요해지면 차단 이벤트 발행 + 서비스별 블랙리스트를 도입합니다. 토큰의 `sid`가 이때 쓰입니다.

## 검토한 대안

- 서비스가 요청마다 Auth에 토큰 상태를 조회: Auth가 모든 요청의 단일 장애점이 됩니다.

## 결과

- 정지해도 최대 `policy.access-token-ttl` 동안 접근이 가능합니다.
