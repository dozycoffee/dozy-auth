# 0012. 1회용 토큰은 verification 테이블 하나로 관리한다

- 상태: 채택
- 날짜: 2026-09-24

## 맥락

초대, 가입 인증, 비밀번호 재설정, 이메일 변경은 모두 "목적이 있는 만료·1회용 비밀값"입니다.

## 결정

- `verification` 한 테이블에 `purpose`, `method`, 해시, 만료, 소비·무효화 시각을 둡니다.
- 목적별 차이(유효 시간, 소비 시 동작)는 코드의 purpose별 정책으로 관리합니다.
- `(principal, purpose)`마다 살아 있는 토큰은 하나입니다.

## 검토한 대안

- 목적별 테이블: 같은 구조와 정리 로직이 반복됩니다.

## 결과

- 새 목적을 추가할 때 테이블 변경이 없습니다.
- 관련 규칙: [VER](../domain.md#7-verification-규칙-ver)
