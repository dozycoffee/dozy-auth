# 0010. 최초 owner는 설정 이메일로 초대하고, 복구는 수동 SQL로 한다

- 상태: 채택
- 날짜: 2026-09-24

## 맥락

처음 배포하면 관리자가 한 명도 없습니다. owner가 퇴사하면 앱 안에서는 복구할 방법이 없습니다.

## 결정

- 기동할 때 owner가 없으면 설정 이메일로 직원을 만들고 `auth:owner`를 준 뒤 초대 메일을 보냅니다. 직원 초대와 같은 흐름을 재사용합니다.
- 설정에는 이메일만 두고 비밀번호는 두지 않습니다. owner가 `ACTIVE`면 설정값을 무시합니다.
- owner 복구는 앱 API로 제공하지 않고, 인프라 관리자가 운영 런북의 SQL 절차로 합니다. CLI는 추후 검토합니다.

## 검토한 대안

- 설정에 초기 비밀번호: 비밀번호가 설정 파일과 배포 기록에 남습니다.
- 복구 API: 원격 공격 경로가 됩니다.

## 결과

- 최초 배포 전에 메일 발송이 동작해야 합니다(local은 Mailpit·콘솔).
