# 0016. OIDC는 쓰지 않고 표시 정보는 /me로 제공한다

- 상태: 채택
- 날짜: 2026-09-24

## 맥락

직접 로그인 API 구조에서는 OIDC의 id token이 필요 없습니다. 앱이 access token을 파싱하면 토큰 형식이 앱과의 계약이 됩니다.

## 결정

- id token과 OIDC discovery를 제공하지 않습니다.
- 앱은 이름, 이메일, role 같은 표시 정보를 `/me`로 조회하고 access token을 파싱하지 않습니다.
- OIDC는 PKCE 확장 때 함께 도입합니다.

## 검토한 대안

- access token에 표시 정보 추가: 개인정보가 토큰에 들어가고 토큰 형식이 앱에 묶입니다.

## 결과

- 토큰 형식은 서비스와의 계약으로만 유지됩니다.
