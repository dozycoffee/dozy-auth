# 0027. 비밀번호 해시는 argon2id로 한다

- 상태: 채택
- 날짜: 2026-09-24

## 맥락

비밀번호 해시는 느리고 메모리를 많이 써야 오프라인 대입에 강합니다.

## 결정

- argon2id를 씁니다. 파라미터는 인코딩 문자열에 포함되므로 나중에 바꿔도 기존 해시를 검증할 수 있습니다.
- 비밀번호가 아닌 난수 비밀값(refresh token, verification, client secret)은 SHA-256으로 충분합니다.

## 검토한 대안

- bcrypt: 입력 길이 72바이트 제한이 있고 메모리 비용을 조절할 수 없습니다.

## 결과

- Bouncy Castle 의존성이 필요합니다.
- 해시 한 번의 시간을 측정해 파라미터를 정합니다.
